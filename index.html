      About Orbit

      Orbit is a browser-based AI study agent built with HTML, CSS, JavaScript and Three.js for a school Work Education activity, with a small Node/Express backend that keeps the AI key off the frontend. All study data (goals, missions, pins, subjects, plans) is saved locally in your browser using localStorage — nothing is uploaded anywhere except AI requests, which go only to your own backend.
